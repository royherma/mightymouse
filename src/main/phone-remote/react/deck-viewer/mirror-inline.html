Mirror layout — four candidates for the admin toggle

Every cell boots the real built bundle. Stacked is what ships today: the pane is fixed at the top and the pad's top is pushed below it. The other three put the screen inside the pad and drop that offset, differing only in how much of the pad the screen claims. Both numbers are measured from live rects and quoted against stacked — pad area you gain, screen area you give up. Nothing connects to the phone-remote server.
