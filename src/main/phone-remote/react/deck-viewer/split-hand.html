Split-hand deck — landscape variants

Four ways to split the landscape control deck across two thumbs, measured at real device viewports with real control dimensions. These are mockups, not the shipped bundle — the split variants don't exist in dist/ yet. What's real here: viewport sizes, safe-area insets, control box sizes scraped from theme.css, and the landscape anchoring rules. The verdict per cell is measured (every control's full box against the thumb arc + against the pad), never eyeballed. Compare with the shipped stacked deck via deck-viewer/viewer.html.
