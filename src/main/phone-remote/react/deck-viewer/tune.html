Landscape tuner

One device, one deck, live values. Every slider rewrites a CSS variable inside the running bundle and re-measures immediately — no rebuild, no page reload. The table on the right is measured from live rects (getBoundingClientRect), never derived from the numbers you typed, so it can disagree with them — and when it does, that gap is the finding. Insets are a simulation of env(safe-area-inset-*), which has no JS setter; they prove whether a layout leaves room, not what iOS reports.
